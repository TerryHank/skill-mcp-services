# Skill MCP Services

Verified stdio MCP services for ModelScope custom MCP deployment.

- mineru-book-mcp: verified upload/download, MinerU parsing, local fallback and Skill ZIP packaging.
- fireworks-graph-mcp: verified upload/download, geometry checked SVG, PNG and offline HTML rendering.

Set MINERU_TOKEN only in the service environment for Standard API. No credentials or source documents are included.
